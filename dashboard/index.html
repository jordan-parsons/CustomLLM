Hadwiger–Nelson · chromatic number of the plane

Attacking 5 ≤ CNP ≤ 7

Every unit distance is confirmed by exact arithmetic in an algebraic number field. Every non-colourability claim carries a machine-checked proof. This page reports what is verified, what is blocked, and what was refuted — including refutations of our own claims.

Where it stands

This is not a record. The smallest known 5-chromatic planar unit-distance graph is 509 vertices (Parts, 2020). Our best verified graph has 510, so it is a reproduction that validates the pipeline — one vertex worse than the state of the art. A record needs ≤ 508; 509 would only tie.

Adversary findings

Adversaries are scored on what they break. A2 found a real hole: the proof checker could report VERIFIED for a satisfiable formula with a zero-byte proof, because a malformed CNF sends drat-trim down a "trivial UNSAT" path before it ever reads the proof. It also showed the float prefilter could miss a genuine unit edge. Both are fixed — the detector is now float-free, using certified rational enclosures — and every prior result was re-verified afterwards to the same proof hash.

Why the search is stuck

  • Deletion-MUS run to fixpoint returns each published graph unchanged. All of them are already vertex-critical — Heule and Parts ran this minimisation first.
  • For the 510 graph, the k=4 UNSAT core is the entire vertex set, and all 510 single-vertex deletions yield 4-colourable graphs. Measured twice, independently.
  • So Parts' 509 is not a subgraph of Heule's 510: the two are structurally different graphs, not a nested chain.
  • Consequence: reaching ≤ 508 means adding ambient points and deleting more than were added. That makes this a construction problem, not the minimisation problem the plan assumed.
